# Catálogo Eixo Esportes

Catálogo responsivo de moda fitness, criado a partir do material oficial da Eixo Esportes. As páginas preservam as imagens e informações do PDF original e todos os botões de compra direcionam para o WhatsApp.

## Desenvolvimento

```bash
npm install
npm run start
```

## Produção

```bash
npm run build
```

O projeto está pronto para publicação na Vercel como aplicação Vite estática.
